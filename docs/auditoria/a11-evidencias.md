# A11 - Evidencias

## Inventario

El Registro de Evidencias contiene **38 registros** distribuidos entre gestión, requisitos, diseño, desarrollo, calidad, seguridad, base de datos y documentación.

## No conformidades documentadas

- especificación formal independiente de requisitos;
- diagramas UML/C4 insuficientes;
- falta inicial de estándar de codificación;
- ausencia de procedimiento formal de respaldo.

## Evidencia técnica reproducible

- reportes Surefire y JaCoCo;
- resultados Playwright;
- resúmenes k6;
- análisis SonarQube;
- artefactos Jenkins;
- historial Git.
