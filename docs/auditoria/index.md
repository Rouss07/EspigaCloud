# Autoauditoría del proyecto

## Introducción

La autoauditoría de EspigaCloud evalúa el grado de cumplimiento del ciclo de vida de desarrollo del software. Comprende gestión, requerimientos, arquitectura, desarrollo, base de datos, seguridad, calidad, interfaces, documentación, manuales, evidencias y configuración del repositorio.

La evaluación usa como referencia **ISO/IEC 12207**, **ISO/IEC 25010**, **CMMI-DEV**, la Guía Scrum y **OWASP Top 10**.

## Objetivo general

Determinar si los procesos, controles y entregables de EspigaCloud proporcionan un nivel adecuado de calidad, seguridad, trazabilidad y mantenibilidad para su evolución y eventual despliegue productivo.

## Alcance

- planificación y seguimiento del proyecto;
- requisitos funcionales y no funcionales;
- arquitectura y código fuente;
- pruebas y calidad estática;
- autenticación, autorización y secretos;
- despliegue mediante Jenkins y Docker;
- documentación técnica y manual de usuario;
- mantenimiento, respaldos y mejora continua.

## Resultado ejecutivo

EspigaCloud presenta un nivel intermedio de cumplimiento, con fortalezas en automatización de pruebas, integración continua y control de versiones. Los riesgos prioritarios se relacionan con la consolidación del plan maestro de pruebas y la gestión de credenciales.
