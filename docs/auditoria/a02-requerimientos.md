# A02 - Requerimientos

## Objetivo

Evaluar la identificación, documentación, validación y trazabilidad de los requisitos funcionales y no funcionales.

## Evidencia

- historias de usuario en JIRA;
- formularios y reglas implementadas;
- pruebas unitarias y E2E;
- manual de usuario y Project Charter.

## Resultado

**Cumple parcialmente.** Los requisitos principales están representados en historias y código, pero falta una matriz formal que conecte requisito, implementación, prueba y evidencia de aceptación.

## Acción recomendada

Crear una matriz de trazabilidad con identificador, prioridad, módulo, clase, caso de prueba, estado y evidencia.
