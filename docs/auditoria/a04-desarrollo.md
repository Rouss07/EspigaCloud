# A04 - Desarrollo

## Objetivo

Comprobar la aplicación de buenas prácticas de codificación, control de cambios, validación y revisión del código.

## Fortalezas

- separación por capas;
- inyección por constructor;
- formularios con Jakarta Validation;
- pruebas automatizadas;
- historial de commits y revisión colaborativa.

## Resultado

**Cumple parcialmente.** El desarrollo es consistente y comprobable, aunque el expediente identificó la ausencia inicial de un estándar formal único de codificación.

## Acción recomendada

Documentar convenciones Java, estrategia de ramas, criterios de revisión, manejo de excepciones y definición de terminado.
